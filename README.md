# Nabihni Electricity – Power BI Dashboard

An interactive Power BI dashboard designed to analyze electrical incident reports and present key insights, trends, and performance indicators for the Nabihni Electricity project.

## Dashboard Preview

![Nabihni Electricity Power BI Dashboard](dashboard%20nabihni.png)

## Dashboard Highlights

- Total electrical reports
- New, completed, and in-progress reports
- Reports by type
- Reports by status
- Latest reports
- Reports over time
- Geographic distribution of reports

## Tools & Technologies

- Microsoft Power BI
- SQL Server
- ASP.NET Core MVC
- Entity Framework Core
